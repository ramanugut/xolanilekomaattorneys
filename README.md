# Xolani Lekoma Attorneys

Marketing website for Xolani Lekoma Attorneys, built as a fast static site with [Vite](https://vitejs.dev/).

## Requirements

- Node.js 22+ and npm 10+

## Getting started

```bash
npm install      # install dependencies
npm run dev      # start the dev server at http://localhost:5173
```

## Available scripts

| Command | Description |
| --- | --- |
| `npm run dev` | Start the Vite dev server (hot reload) on port `5173`. |
| `npm run build` | Produce a production build in `dist/`. |
| `npm run preview` | Serve the production build locally on port `4173`. |

## Project structure

```
index.html          # Page markup
src/main.js         # Interactive content + contact-form validation
src/style.css       # Styles
public/favicon.svg  # Site icon
vite.config.js      # Dev/preview server config (binds 0.0.0.0)
```
